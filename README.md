# MoodScape 🌈

MoodScape is a simple, interactive web project that lets you choose your vibe using emoji buttons.  
Each mood changes the card’s background, text, and color scheme with smooth transitions — making it a fun way to reflect your emotions in real time.

---

## ✨ What This Project Does
- Displays a **reminder card** that adapts to your chosen mood.
- Clicking an emoji updates the **quote, background color, and text color** dynamically.
- Smooth **fade-in/out transitions** make the experience feel polished.
- Optional **auto-test mode** cycles through moods automatically (for demo/testing).

---

## 🚀 Features
- **Minimal HTML** → clean structure, just one card and emoji buttons.
- **CSS polish** → hover effects, smooth transitions, subtle scaling.
- **JavaScript logic** → modular functions, mood mapping, fade animations.
- **Personalization** → over 20 moods with unique quotes and color themes.
- **Developer mode** → auto-test function to cycle moods for testing.

---

## 🎯 Why This Project Was Made
This project was created as a **practice and showcase**:
- To strengthen JavaScript skills (DOM manipulation, event handling, modular code).
- To experiment with CSS transitions and hover effects.
- To build a fun, aesthetic project that demonstrates creativity and interactivity.
- To serve as a **portfolio piece** for learning and testing web development concepts.
